# 天穹遗嘱 · Sky Testament

> 你出生那晚的天空，被做成了一张可以打印的遗嘱。

Sky Testament 是一个**天文记录生成器**。输入一个真实的时刻与地点，它还原那一刻真实可见的天空，并写下一段克制的文字作为注脚。它不预测命运，只记录天空。

**状态**：M6 开发中 · v0.6.1（实时与左侧信息栏）已完成

---

## 它是什么 / 不是什么

| 是 | 不是 |
|---|---|
| 真实天文计算（恒星、行星、月球、地平线） | 占星术、星座运势、命理解读 |
| 一张可打印、可验证的纪念物 | 社交产品、内容社区 |
| 确定性的：同一输入永远得到同一结果 | 随机鸡汤生成器 |
| 私密的：日期与地点不离开浏览器 | 需要上传个人数据的云服务 |

**伦理边界**：不含任何对未来的预测，不做健康、财富、婚姻判断，不使用「命中注定」「运势」这类表述。星图是天文事实，文字是文学修辞，二者都不构成命运判断。

## 三条核心原则

1. **真实** —— 不是插画，是算出来的天空。每一个点都有坐标、时间和误差范围。
2. **确定** —— 同一输入，任何浏览器，逐字节相同的 SVG。
3. **可印刷** —— 从网页变成能挂在墙上的东西：A3、矢量、字体嵌入、文本可选中。

## 技术方案

```
Browser (SPA，无后端)
├─ core/          纯 TypeScript，与框架无关
│   ├─ time        UTC 锚定 + 手动偏移覆盖
│   ├─ ephemeris   astronomy-engine（VSOP87 / NOVAS）
│   ├─ catalog     星表二进制 + 自行修正
│   ├─ projection  球极投影（保角）
│   ├─ text        模板 + 语料 + xoshiro128**
│   └─ scene       与渲染无关的场景图
├─ render/
│   ├─ svg.ts      屏幕渲染与 SVG 导出
│   └─ pdf.ts      V1：pdf-lib + fontkit 子集嵌入
└─ data/           stars.bin · cities.json · 字体子集
        ↓
  静态托管（Cloudflare Pages / GitHub Pages）
```

关键决策：

| 决策 | 选择 | 理由 |
|---|---|---|
| 后端 | 不做 | 计算、渲染、导出、分享全部在客户端完成 |
| 天文库 | astronomy-engine (MIT) | 标称 ±1′，与 JPL Horizons 交叉验证，无 DOM 依赖 |
| 时区 | **种子锚定 UTC 时刻**，而非本地时间 | 绕开浏览器 tzdata 差异，跨端可复现；本地→UTC 结果展示在元数据中并允许手动覆盖 |
| 投影 | 球极（stereographic） | 保角，星座在地平线附近仍可辨认；全屏缩放通过 viewBox 裁剪实现，矢量始终按屏幕分辨率重绘 |
| 星表 | HYG v4.2 过滤 mag ≤ 6.5 | 单文件、含自行与星名；CC BY-SA 4.0，独立目录 + 署名 |
| 文案 | 模板 + 语料 + 确定性 PRNG | 不用 LLM：零成本、零延迟、零隐私风险、可复现 |
| 导出 | MVP 用浏览器打印，V1 上 pdf-lib | Chrome 打印保留矢量并嵌入字体子集，A3 已验证 |
| 确定性 | 固定精度序列化 + 固定字宽度量表 | 不依赖 getBBox、Intl 或 Math.random |

## 精度目标

| 项 | 目标 | 验证方式 |
|---|---|---|
| 行星位置 | < 0.02° | 10 组样本对照 JPL Horizons |
| 恒星位置 | < 0.05°（含自行修正） | 同上 |
| 月相照度 | < 0.5% | 对照 USNO |
| 日出日落 | < 1 分钟 | 对照 Horizons |

实测（2026-10-19 12:00 UTC，上海，对照 JPL Horizons）：火星 0.03′、木星 0.04′、月亮 0.04′、金星 0.33′，均远优于目标。

已知边界（会写进 README 与 PDF 页脚）：

- 1970 年之前的时区规则为回推数据，精度有限，提供手动 UTC 覆盖
- 未建模海拔与地平线下沉，高海拔地点的日出日落可差数十秒
- 恒星位置为 J2000 加自行外推，未做视差修正

## 隐私

- 日期、坐标、文案全部在浏览器内计算，**不上传、不记录、不分析**
- 分享链接包含时间与位置，生成时明确提示，并提供「模糊到城市级」选项
- 不引入第三方统计脚本，不做用户画像
- 生成的星图与文字归用户所有

## 开发

环境：Node **20.18+** 与 npm。不使用 pnpm——Windows 默认没有创建符号链接的权限。

```bash
npm install
npm run dev      # 开发服务器，http://localhost:5173
npm test         # 单元测试（含 JPL Horizons 对照）
npm run ephem    # 命令行打印天体高度与方位
npm run build    # 类型检查 + 生产构建
npm run shot     # Playwright 截图（channel: chrome，不下载内核）
```

数据管道（原始数据放在 `data-raw/`，不提交）：

```bash
npm run build:stars    # HYG v4.2 → public/data/stars.bin + star-names.json
npm run build:cities   # GeoNames cities15000 → public/data/cities.json
npm run build:font     # Noto Serif SC → public/fonts/*.woff2
```

原始数据下载地址：`hygdata_v42.csv.gz`（astronexus.com）、`cities15000.zip`（download.geonames.org/export/dump）、
`NotoSerifSC[wght].ttf`（google/fonts）。

已完成：

- **M1 天文核心** —— `src/core/time.ts` 本地时间 → UTC，覆盖夏令时前拨与回拨；`src/core/ephemeris.ts` 太阳、月亮、五大行星的赤道与地平坐标；4 个天体对照 Horizons，最大偏差 0.33′
- **M2 数据层** —— 恒星目录 8,920 颗（mag ≤ 6.5，含自行与 B−V）、城市库 6,285 座（3,588 座带中文名）、字体子集 1,758 字；城市搜索可直接回填时区与经纬度
- **M3 星图** —— 球极投影的可见半球、星等分五档合并为 path、七座星座连线（自绘）、亮星与行星标签避让、地平圈与方位刻度、白天模式；点「查看星图」进入全屏，拖动平移、滚轮或双指缩放（最高 14 倍）；缩放改的是 SVG viewBox 而非 CSS transform，因此任意倍率都是矢量重绘，标签字号与描边保持屏幕尺寸不变
- **M4 夜空观感** —— 深色夜空与纸面两套主题（白昼自动切纸面）；光污染限等预设（暗夜 6.5 / 郊外 5.5 / 城市 4.0 等）；恒星按 B−V 分四档着色；月球按真实照亮比例与盈亏绘制相位盘；三档信息密度（纯净 / 标准 / 图谱），图谱叠加黄道、天赤道、30° 与 60° 高度环标注、八方位、星座拉丁缩写、行星星等与月相文字
- **v0.5.1 文案引擎** —— 纯 TS SHA-256 + xoshiro128\*\*，种子锚定 UTC 时刻与坐标；从快照提取月相、可见行星方位、最亮恒星与季节；古典 / 现代两种风格，模板 + 人工语料；禁用词过滤与月相一致性由测试保证
- **v0.5.2 这一夜** —— 用天文搜索求出日落、民用暮光、晨光与日出，时间轴覆盖整夜；拖动实时预览（松手才写回表单并重新生成文案），播放支持 0.5× / 1× / 2× 倍速（2× 时整夜约 9 秒）；可用两侧按钮切换到前一日 / 后一日，跨午夜时日期自动进位
- **v0.5.3 天体详情与天象** —— 点击星图上的恒星、行星或月亮查看星等、色指数、高度方位、升落与中天；自动识别这一夜的月食、月合行星（角距 < 5°）与流星雨极大，并把天象写进文案开头；宽屏下改为两栏：星图与文案在左，时刻表、天象与数据在右侧信息栏（随滚动吸顶）

- **v0.5.4 两页结构** —— 输入与结果拆成两页：第一页只留时间与地点，第二页是「左图右文」的舞台。右侧信息栏独立滚动，星图固定在左侧并随窗口高度缩放；画面 / 质量 / 图例移到顶栏。同时修复三个问题：全屏星图因指针捕获无法点选、拖动平移误触发选中、流星雨按 UTC 日期匹配导致跨时区错一天。全屏信息卡改为贴着被点天体显示，并随缩放平移跟随

- **v0.5.5 双时刻与恒星命名** —— 顶栏「双时刻」进入对比模式：默认十年前同一天同一钟点，两张星图并排、各自成文，顶部可改对比时刻并显示相隔天数。恒星详情支持中英双语：有中文名时显示「娄宿三/Hamal」+ HIP 编号，没有中文名时退到英文专名、星座 + 拜耳字母，中文星名从 39 个扩到 127 个，并补齐 88 个星座的中文对照。另修复：拖动时间轴时文案消失、UTC 时间折行

- **v0.5.6 可缩放的星图** —— 二屏星图支持滚轮缩放（1×–5×）与拖动平移，地平圈、方位刻度与 N/E/S/W 固定不动，星空内容被地平圈裁剪；标签字号随缩放反向补偿，放大后仍然清晰。点选判定会按缩放和平移反算坐标。另从 README 删除与实际情况不符的路线图章节

- **v0.5.7 信息卡冻结** —— 修复拖动时间轴时天体信息卡消失：卡片改为只认已提交时刻，拖动时保持原状，松手后才按新时刻重新确认；天体若已落下，卡片才消失

- **v0.6.0 行星观感** —— 行星不再是单色小圆：每颗行星有自己的色调（水星灰白、金星暖白、火星橙红、木星米黄、土星淡金、天王星青、海王星蓝），外圈是径向渐变泛光，按星等分级（金星木星最大，海王星最小），并加低强度十字星芒——角度按天体 id 哈希，各自偏转不同。缩放时标记尺寸按 √zoom 缓慢变大，不再随天空线性放大；星点、月亮与选中环同样处理，所以放大后仍是「星图」而不是一堆大圆点

- **v0.6.1 实时与左侧信息栏** —— 顶栏「实时」进入实时模式：每秒按当前时刻重算，跨过日出 / 日落自动切换夜空与纸面，页面隐藏时暂停，停止后按此刻生成文案；实测单次重算 5–9ms，1Hz 开销可以忽略。暗行星（星等 ≥ 3）补上长度下限的星芒，海王星、天王星也看得见。左侧新增信息栏：天体表在上、选中天体信息在下，沿用右栏的细线排版；星图右移并缩到 700px 让出通道。另修复拖动放大星图时触发浏览器文字选中的问题，以及全屏星空按钮与星图中心不齐

测试共 104 个。
